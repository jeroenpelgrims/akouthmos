# Akouthmos

A web app for practicing language vocabulary: it serves you words, checks your
answers, gives feedback, and provides audio pronunciation.

The name **Akouthmos** is a blend of two Greek words:

- **ἀκούω (akoúō)** — "to hear / to listen"
- **ἀριθμός (arithmós)** — "number"

## Usage

The app is live at **https://akouthmos.jeroenpelgrims.com**

## Development

Built in Rust with [axum](https://github.com/tokio-rs/axum) and
[Askama](https://github.com/askama-rs/askama) templates.

```sh
cargo run
```

Then visit http://localhost:3000
